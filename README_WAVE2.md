## 🔑 Key Information

### Three Credentials Needed
```
NEXT_PUBLIC_SUPABASE_URL        (public)
NEXT_PUBLIC_SUPABASE_ANON_KEY   (public)
SUPABASE_SERVICE_KEY            (secret!)
```
→ Get from: Supabase Settings → API
→ Store in: .env.local (never commit!)

### Critical Configuration
- ✅ Disable email verification (Task 4)
- ✅ Set session TTL: 7-30 days (Task 4)
- ✅ Create profiles table (Task 5)
- ✅ Enable RLS on profiles (Task 6)

### Database Schema
- profiles table with 9 columns
- Links to auth.users via foreign key
- RLS enabled with 4 policies
- Indexes on role and is_active
