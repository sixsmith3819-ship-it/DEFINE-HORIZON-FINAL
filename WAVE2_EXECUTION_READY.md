## 💡 Key Points to Remember

1. **Three credentials needed**:
   - `NEXT_PUBLIC_SUPABASE_URL` (public, safe)
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` (public, limited)
   - `SUPABASE_SERVICE_KEY` (secret, never expose)

2. **Critical configuration**:
   - Disable email verification in Task 4
   - Set session TTL to 7-30 days
   - Store credentials in .env.local (gitignored)

3. **Database structure**:
   - profiles table links to auth.users
   - RLS enables user data isolation
   - Indexes optimize queries
   - 4 policies control access

4. **Security**:
   - Never commit .env.local to git
   - Service key bypasses RLS (server-side only)
   - Browser uses limited anon key (respects RLS)
   - All credentials required for Phase 3
